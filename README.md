# Sistema-Integrado-de-Gesti-n-y-M-tricas-de-Atenci-n
Es una aplicación web, basada en Google Sheets y Apps Script, para registrar y visualizar indicadores de rendimiento de atención al cliente. Ofrece paneles interactivos para analizar métricas por canal (Presencial, Telefónico, Virtual) y gestiona el acceso de usuarios mediante roles.
